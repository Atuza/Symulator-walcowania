# 0002. DXF R12 with a single closed polyline

Status: accepted
Date: 2026-10-27

## Context

The contour goes to CAD and cutting software of unknown versions. It must be one unbroken outline on
layer `cut`, red, 1:1 in mm.

## Decision

Write DXF R12 (AC1009) by hand: one closed `POLYLINE` with arc segments as bulges. Arcs are split in two
so no bulge approaches the 180° singularity.

## Consequences

R12 is read by virtually all software and needs no object handles. R12 has no unit header, so the file
relies on the 1:1 mm convention. No extra dependency.
