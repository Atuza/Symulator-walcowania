# 1.1.7 - Circumference editing and eccentric edge dimensions

Date: 2026-10-29.

Click C on a cylinder drawing or C1/C2 on either cone type to enter the finished-part circumference.
The selected reference surface determines the matching diameter and radius; development, mass and
the 3D preview recalculate from those inputs. Circumference excludes flat-end allowances.

Cylinder cut length is also editable on the development drawing. The existing thickness-aware
inverse calculates the diameters automatically. The diameter/blank mode selector and duplicate
sidebar length field are removed. Legacy reverse-mode links and saved jobs remain readable.

The editor previews linked dimensions and rejects candidates with invalid geometry or non-finite
results, leaving the previous valid part intact. Cone end order, wall thickness and apex validity
remain governed by the existing solvers; machine warnings continue to flag capacity limits.

Eccentric-cone developments now dimension both numerical edge curves as L1/L2. Values are integrated
net arc lengths, not chords or bounding sizes. Flat allowances are shown separately. Separate
dimension lanes and sufficient margins keep labels readable in SVG and PDF.

Verification covers surface-aware circumference/diameter/radius edits, cut-length inversion,
allowances, rejected edits, saved-link precision, true eccentric edge lengths and narrow/screen/PDF
dimension placement. Full tests, lint, TypeScript, formatting, production build, browser editing,
PDF rendering and DXF comparisons are checked before publication. The tagged release records the
terminal CI and deployment results. Installed-machine geometry is preserved and v1.2 remains deferred.
