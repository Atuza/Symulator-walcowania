# 1.1.8 - Direct dimension editing and cones at the machine

Date: 2026-10-29.

Thickness is permanently beside the material grade. Tank, ellipse and free shapes are removed from
the shape picker and reference picker; existing saved calculations remain readable.

Diameter dimensions display editable Ø and R together; cone end dimensions also show their C1/C2
circumferences. Development radii and eccentric generator lengths now sit at their corresponding
arcs and edges instead of separate footer controls. The large result buttons open the matching editor
and long values stack so they remain readable.

Active-shape dimension lines have input bindings, including developed arc lengths, blank extents and
profile cut length. The last edited measure drives one validated transaction after Enter or Apply.
The editor previews coupled dimensions and explains proportional scaling for overall developed sizes.
Invalid geometry stays in the editor and leaves the current part intact. Crowded blank intervals use
separate dimension lanes.
When a dense drawing cannot fit an A4 report column, the PDF adds a full drawing page and links to
it from the report instead of omitting a view.

Both cone previews include the installed machine, aligned to the current contact generator while
preserving true roll dimensions. Machine context is illustrative; tilted-roll and CNC setup are not
calculated. Geometry calculations and cut contours are preserved.

Validation includes all eight offered shapes, surface-aware inverse edits, closure, allowances,
invalid candidates, touch targets, zero apex ends and cone contact frames. Full tests, lint, TypeScript,
formatting, build, desktop/mobile browser editing, rendered PDFs and control DXF comparisons are
checked before publication. The tagged release records terminal CI and deployment receipts.

The v1.2 machine-program editor remains deferred.
