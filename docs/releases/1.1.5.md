# 1.1.5 — Fixed installed-machine roll dimensions

Date: 2026-10-28.

The application uses one fixed machine geometry: top roll Ø 338.38 mm, bottom Ø 310.12 mm, both side
rolls Ø 240.02 mm, working length 3100 mm and maximum plate width 3000 mm. The machine editor shows
these values as read-only definitions. Old settings, imported machine/configuration files and reset
cannot replace them; other settings and saved calculations keep their existing format.

The 3D preview respects the configured roll length rather than enlarging it to fit the plate. Real
machine warnings now appear for bends that cannot clear the top roll and plates wider than 3000 mm.
These warnings do not change the geometric calculation or disable direct dimension editing.

Verification: 243 tests cover legacy/import normalization, preserved configuration, exact 3D roll
dimensions, physical-limit warnings and unchanged geometry, mass, springback and drawings for all
11 shapes. Lint, TypeScript, formatting and the production build are checked before publication,
along with the machine editor and update in the production browser.

The v1.2 machine-program editor remains deferred. The tagged GitHub release records the published
commit and CI/deployment receipts.
