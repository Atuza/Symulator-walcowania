# 1.1.2 — Edit dimensions on the drawing

Date: 2026-10-28.

## Changes

- Click or tap an underlined input dimension to change it directly from the drawing. This includes
  section sizes, bend radii, straight lengths, arc angles, thickness, plate width and cone dimensions.
- Use Enter or Apply to validate and commit the change. Both views, the form, results, mass, warnings
  and subsequent exports use the updated inputs. Preview the new blank length before committing.
  Esc or Close cancels; invalid values leave the last valid part intact.
- Preserve reference-surface and radius/diameter semantics. Individual free-profile lengths, radii
  and signed angles can be edited independently. Semicircle radii remain tied to their diameters.
- Keep developed blank length and derived measures read-only. Plate width is an independent input
  and remains editable on the development view.
- Support mouse, touch, keyboard activation and focus restoration. Long drawing annotations can
  scroll on small screens. Correct the narrow-screen panel minimum width.

The existing Geometry form remains available. The v1.2 machine-program editor remains deferred.
