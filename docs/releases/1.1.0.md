Release date: 2026-10-28.

## Scope

The 1.1 work covers additional rolled profiles, machine capability checks, dimensioned A4/A3 reports,
the machine preview and an eccentric cone development. A machine-program library/editor is outside
this release.

## Finishing fixes

- QR captions stay above the code instead of overlapping the PDF results and warnings.
- Drawing annotations wrap inside their view; eccentric generator notes use separate lines.
- Shape reference in edit mode explains inputs, ranges, formulas, examples and model limitations.
- Template descriptions use the correct profile name and dimensions, including cone offset.
- Negative, non-finite and invalid text offsets cannot silently produce a different cone.
- Existing link defaults and storage versions remain unchanged.

## Limits

The preview is geometric. It does not solve CNC axis positions, contact forces, deformation or
collisions. Cones show the plate without the machine or tilted rolls. Capacity checks on profiles
other than cylinders are indicative.

Eccentric thickness conversion uses mean wall slope, so it approximates a finite-thickness wall.
Ellipse graphics approximate the continuously changing curvature with short arcs. Free-profile
closure does not validate self-intersections. Verify production geometry on a trial part.
