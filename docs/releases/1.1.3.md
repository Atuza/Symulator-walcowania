# 1.1.3 — Stable interactive drawing resize

Date: 2026-10-28.

Includes [direct dimension editing](1.1.2.md) and defers drawing resize writes to the next animation
frame. Updating the SVG can change its scrollbars and observed width; performing that write inside
the resize notification could raise a ResizeObserver feedback-loop error during a responsive layout
change. The change coalesces notifications and leaves the geometry and export calculations unchanged.

Verification: all 182 tests, lint, TypeScript, formatting and the production build pass. The dimension
editor and small/large viewport transitions are checked again in the production browser.

The developed blank length remains read-only. The v1.2 machine-program editor remains deferred.

The [tagged release](https://github.com/Atuza/Symulator-walcowania/releases/tag/v1.1.3) records the
published commit and CI/deployment receipts.
