# 1.1.9 - Keep large result values in one column

Date: 2026-10-29.

Includes the direct drawing dimensions, permanent material thickness field, eight-shape picker,
cone machine context and dense-PDF drawing page introduced in 1.1.8.

Reset the last result cell's two-column span when long values require a single-column layout.
Without the reset, the cone's third result created an implicit second grid track and the large R1/R2
values still overlapped. Calculations, drawing geometry, PDF layout and DXF output are unchanged.

Verify the corrected result panel on the public shallow-cone case alongside the 1.1.8 regression
evidence. The final commit is checked by CI and GitHub Pages deployment before publication.
