# 1.1.11 - Automatic P460NL2 cylinder profile at every thickness

Date: 2026-10-30.

Selecting P460NL2 now selects a process profile that scales the cut adjustment with thickness:
**−0.4110837869 × t mm**. It uses the report's alternative thickness fit rather than applying a
fixed −3.989 mm outside the measured series. For t5/t10/t20 the adjustments are approximately
−2.055/−4.111/−8.222 mm. At inner Ø2380 and t10, cut length is **7504.30 mm**.

The profile operates at every positive thickness. Outside the measured t9.2–10.0 / outer
C6916–7548 mm range it displays a prediction warning. This is a calibrated process model for
the installed machine, not a validated material law for all P460NL2 thicknesses. Manual k and
flat-end allowances retain their precedence. Both cone types remain excluded.

Users select cylinder and P460NL2, enter thickness beside the grade, then edit Ø, R, circumference
or cut length on the drawing. Enter updates all linked dimensions, exports and mass.

Old saved cuts and QR links keep their original calculation model. A single "Use profile for all
thicknesses" button upgrades an older calibrated job; new jobs and version-3 links use the new
profile automatically. The cylinder inverse now assigns the converged k before returning, keeping
its reported k, diameter and geometric ring consistent at tight R/t as well.

Verification covers the expanded thickness range, both inverses, reference surfaces, model
persistence/migration, automatic grade selection, existing cone/profile exclusions, browser edits
and A4/A3 PDF/DXF output. CI and Pages must finish for the published commit before deployment
is reported as complete. v1.2 remains deferred.

Local validation: 372 unit tests and all 33 desktop/phone/iPad browser cases passed, with the
updated persistence wait checked again on all three devices. Lint, TypeScript, Prettier and the
production build passed. A4/A3 exports were rendered and visually reviewed with no off-page text.

The first hosted run exposed timeouts in the combined navigation/export scenarios. Separate those
into focused checks, navigate once per link with a distinct query, and run one browser worker in CI
to avoid competing software-rendered 3D scenes. The same edit, persistence, export, legacy-link and
cone-isolation assertions remain; there are now 39 browser cases across the three devices.
All 39 focused cases passed locally with one worker and no retries.
