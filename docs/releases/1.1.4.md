# 1.1.4 — Independent radii and lengths on every drawing

Date: 2026-10-28.

Each profile bend has its own editable radius, and every straight and overall size can be changed
on the drawing. Closed profiles retain their seam closure; the editor previews linked adjustments
before applying. Separate corner-angle controls are omitted. Existing arc sweeps remain available
for half-round, bucket and free profiles.

The sidebar hides duplicated geometry fields. An enlarged drawing dialog gives the dimensions more
room. Labels use dedicated gutters and routed leaders. The same drawing placement is used by PDF.
Ellipse curvature radii and cone sector radii/generators support inverse editing through the existing
geometry models. The total developed blank length remains read-only.

Modified profiles are retained in saved inputs, templates, history, PDF reports and QR links. A reset
restores the selected shape's preset. Flat-end allowances are included in overall measurements while
the editable straight lengths remain separate from them.

Verification covers 219 tests, lint, TypeScript, formatting, the production build, all 11 shape tiles,
independent-radius editing, cancellation, persistence, PDF and DXF exports, and small/large layouts.

The v1.2 machine-program editor remains deferred. The tagged GitHub release records the published
commit and CI/deployment receipts.
